## Selected work

### [Pharmaceutical demand forecasting](https://github.com/LuisCBaez/demand-forecasting-system-design)

**Professional work · public methodology case study**

Developed a user-triggered monthly forecasting workflow using Python, Databricks and MLflow.

- Prepared inconsistent business inputs and analysed different demand patterns.
- Compared baselines, statistical methods, intermittent-demand methods and LightGBM.
- Worked with finance, supply and business analysts on requirements, forecast interpretation and review-ready outputs.

The public case study covers the methodology, architecture and evaluation limitations through diagrams and pseudocode. Client code, data and results remain private.

### [Geothermal well-log ML](https://github.com/LuisCBaez/well-log-ml)

**Research collaboration associated with TU Delft doctoral research**

Investigated geothermal property prediction by combining laboratory measurements with well-log data. Built preprocessing workflows, compared regression and gradient-boosting models, and used validation grouped by well during tuning.

The methodology contributed to Chapter 5 of [P. Kolah Kaj’s 2026 doctoral thesis](https://repository.tudelft.nl/record/uuid:8efba807-22a3-4f9f-b73e-5afbce251966). The repository documents the limits of the four-well study; original research inputs are restricted.

### [MSc thesis: predicting missing well logs](https://repository.tudelft.nl/record/uuid:873cc936-d799-40c6-97d5-b168012ad090)

**TU Delft master’s thesis**

Evaluated MICE-based imputation with XGBoost, Random Forest, KNN and Bayesian Ridge. Explored how preprocessing, data quality and geological differences affected the estimation of missing measurements.

[Thesis code](https://github.com/LuisCBaez/Predicting_Well_logs_MICE_TUDelft_Msc_Thesis)

### [Tetouan Power MLOps](https://github.com/LuisCBaez/tetouan-power-mlops)

**Personal project · in development**

A practical project for developing my ML workflow and software engineering skills. It estimates power consumption using weather and calendar features recorded at the same timestamp.

Implemented data processing, model experimentation and feature engineering, with Python packaging, automated tests, GitHub Actions CI, Databricks and MLflow.

My next focus is a reproducible batch-inference workflow with input checks and recovery procedures.
